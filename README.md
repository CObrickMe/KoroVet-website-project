Проєкт «КороВет» — Вебсайт ветеринарної клініки
Сайт створений в процесі виконання лабораторних робіт, ніякої ветеринарної клініки не існує, інформація не реальна, всі збіги випадкові
Сучасний, повністю адаптивний та оптимізований вебсайт для ветеринарної клініки. Проєкт розроблено з використанням підходу Mobile-First, з акцентом на доступність (WCAG 2.2 AA), семантичну розмітку та високу продуктивність.
Основні особливості
Адаптивний дизайн: коректне відображення на екранах будь-якого розміру завдяки utility-класам Tailwind CSS.
Семантика та Доступність (a11y): правильне використання HTML5-тегів, підтримка клавіатурної навігації (skip-link, focus-стани), aria-атрибути та високий контраст кольорів.
Ембеддинг медіа: інтегровані віджети Google Maps та YouTube із сучасними пропорціями та лінивим завантаженням (loading="lazy").
Функціонал: інтерактивна форма калькулятора для розрахунку орієнтовної вартості послуг.
Використані технології
HTML5 та CSS3 (глобальні змінні)
Tailwind CSS (через CDN)
FontAwesome (v6.6.0) та Google Fonts
Netlify (хмарний хостинг)
Результати Google Lighthouse (Desktop)

Локальний запуск
Завантажте файли проєкту на свій комп'ютер.
Відкрийте папку проєкту в редакторі коду (наприклад, VS Code).
Натисніть правою кнопкою миші на index.html та виберіть "Open with Live Server" (потребує встановленого розширення).
Розгортання
Проєкт розгорнуто та підтримується на платформі Netlify. Оновлення здійснюються шляхом завантаження нових файлів через панель керування (Deploys).
